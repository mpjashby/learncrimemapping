# Project instructions

## R code style and readability

- All R code for this project must comply with the
  [tidyverse style guide](https://style.tidyverse.org/).
- Use tidyverse tools wherever possible, choosing functions and workflows that
  make the code clear and consistent with the rest of the project.
- Include explanatory line-by-line comments throughout the code so that a new
  person taking over the project can easily understand what each step does and
  why it is needed. Explain assumptions, non-obvious logic and important design
  choices, and keep comments up to date when the code changes.
- Preserve deliberate errors and style violations in student-code test fixtures:
  these are inputs used to test the checker, rather than examples of project
  coding style.
